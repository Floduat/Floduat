## `~/about`

Full-stack developer who ships to production, not to a portfolio folder.
I take a business that runs on spreadsheets and phone calls and turn it into a system that runs itself.
Backend in Django, frontend in React + TypeScript, bots where the customer already is, everything else on my own homelab.

```yaml
focus:     ERP, automation, insurtech
languages: [Russian, Belarusian, Polish, English]
infra:     Arch Linux, homelab, Cloudflare Tunnel
mindset:   build it, ship it, scale it
```

## `~/building`

| Project | What it is | Stack | Status |
|:--|:--|:--|:--|
| **ERP** | ERP for a construction materials business. Replaced a legacy system, the team runs on it daily | Django · React · TS | in production |
| **Border insurance bot** | Insurance for non-EU cars entering the EU, bought in a couple of taps in Telegram | Python · Telegram Bot API | MVP |
| **Homelab + MCP** | Self-hosted services and my own MCP connector so AI agents can talk to my stack | Arch · cloudflared · Python | running |
| **Marketing infra** | Static site on GitHub Actions, prices pulled from Sheets, full GTM + GA4 + Google Ads tracking | GH Actions · GTM · GA4 | live |
